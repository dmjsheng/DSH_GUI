# DSH GUI V0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows-friendly Electron desktop wrapper that opens DeepSeek Harness from `D:\DSH` with a double-clickable GUI.

**Architecture:** The Electron main process owns the desktop window and delegates all Harness lifecycle behavior to a small backend launcher module. The launcher resolves local paths, starts `pnpm dsh web` only when the configured local URL is not already responding, waits for readiness, and stops only the child process it created.

**Tech Stack:** Node.js ESM, Electron, electron-builder, Node built-in `node:test`, PowerShell/Windows process tools.

**Spec:** User-approved in-chat design on 2026-08-17: GUI source in `D:\DSH_GUI`; backend Harness remains at `D:\DSH`; auto-set `DSH_HOME=D:\DSH\.dsh`; load `http://127.0.0.1:3080`; use `DSH-logo.png`; push source to `https://github.com/dmjsheng/DSH_GUI` and tag `V0.1`.

## Global Constraints

- Do not copy the full `D:\DSH` checkout or `node_modules` into this repository.
- Default Harness root is `D:\DSH`.
- Default Harness home is `D:\DSH\.dsh`.
- Default URL is `http://127.0.0.1:3080`.
- The app must work by double-clicking a packaged Windows executable.
- The app must not kill a pre-existing Harness process that it did not spawn.
- The Git tag for this release is exactly `V0.1`.
